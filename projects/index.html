# Projects

Open source is close to my heart, as an idea and in practice: software gets better when it's built in the open. I contribute where I can and want to do more of it. Some things I've built or helped build:

  • -

    gast

    : a terminal dashboard for your GitLab activity, written in Go. Yes, this site and that tool share an aesthetic.
    $ brew install pataar/tap/gast
  • -

    pataar.github.io

    : this website. Astro, Tailwind, zero client-side JavaScript, and the terminal aesthetic you're looking at.
  • -

    efteling-node-exporter

    : a Prometheus exporter for ride wait times at the Efteling. Built to learn Rust; kept because Grafana dashboards of rollercoaster queues are great.
  • -

    browser-detect

    : browser detection for Laravel. I keep the package alive through my fork.
  • -

    mainsail

    : web UI for Klipper 3D printers. I was part of the Mainsail-crew for a while, back when my 3D printing hobby and my day job overlapped.
